# SDG Timesheet System — Staff User Guide

Staff sign in through the organisation’s configured authentication portal. The Staff Dashboard shows today’s attendance, leave balances, notifications, and the active timesheet workflow. Staff should acquire GPS before checking in, complete every applicable task detail, and submit the timesheet before checking out. If GPS acquisition fails or accuracy is poor, use **Retry GPS**; the system preserves the record and provides the configured manual-review path when available.

A timesheet can contain multiple tasks. Each task captures duration, activity type, specific activity, stakeholder, location or platform, output, engagement numbers, outcome, follow-up, evidence, status, challenges, and country-coordination details where applicable. Staff can review previous leave requests and archived monthly timesheet history from their dashboard.

Leave requests use the configured entitlements of 21 annual working days, 5 sick days, 90 maternity days, and 999 unpaid days. Weekends and configured public holidays are excluded from annual-leave day calculations. Request status and approval or rejection remarks are shown in the Staff leave history.
